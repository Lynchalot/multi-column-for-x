# Release notes for addons.mozilla.org ("Version notes" when a version is uploaded)

Short, for the box on the upload page; the full history is CHANGELOG.md.

**Next upload (the first from this work):**
- Settings now open in a panel over the page from the gear in the bar, and from the toolbar button; search finds any setting, and a Reset puts one back.
- Presets that can all be picked: Just columns, Calm, Media wall, Custom.
- Click X's logo to fold its menu to icons; Alt+[ and Alt+] too. The columns grow into the room.
- Photos: the mouse wheel steps between them in the full-size viewer. Videos stay full screen.
- Translation starts when you point at the button and rides the comments fetch, so it is quicker.
- Vimium and similar: j, k, d, u, gg and G scroll the columns.
- X as the default name and logo (Twitter's is still an option).
- When X changes something the extension depends on, the one feature switches off with a message, or the columns hand back X's own page with a Report button. Settings, Troubleshooting has a table of what is working; "Save sample" in a post's ... menu keeps what is needed to fix a change (words, names and addresses removed; nothing is sent).
- Text size setting; a quieter start-up; the target size of everything pressable is at least 24 px.
